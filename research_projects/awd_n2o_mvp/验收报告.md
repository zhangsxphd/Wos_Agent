# AWD 与持续淹水：v0.9 MVP 实际运行

## 运行入口

在仓库根目录，使用已安装 `pdfplumber` 的 Python 执行：

```sh
python research_projects/awd_n2o_mvp/run.py --manifest research_projects/awd_n2o_mvp/manifest.json --sources outputs/awd_mvp/sources --out outputs/awd_mvp/run
```

缺文件时入口从清单内公开链接下载，校验 SHA-256；文件变化时停止。2026-11-01 曾从空目录实际下载后运行，得到 2 篇论文、2 条比较、1 组跨论文可比性判断、0 项共同发现。此前一次默认 Python 请求对第二篇返回 403，使用普通公开文件请求头重试成功；网络访问仍可能受服务器限制。已有全文可以直接放到 `--sources` 指定目录，不重新请求。

入口从原始 XLSX 和 PDF 读取指定单元格/页面，将逐篇候选送入现有 `convert_historical_candidates.run()`、`evidence_synthesis.adapt_converted()` 和 `synthesize_converted()`；不读取已有转换 JSON 或预写比较数值。程序写候选、转换记录、[规范化证据](normalized_evidence.json)、[综合](synthesis.json)及[运行记录](run_log.json)。

**人工步骤：** 先按原始水稻试验、有 AWD 和持续淹水对照、有生育季累计 N₂O 与可公开读取原文选择论文，不按结果方向选择；随后核查原文并在 [manifest](manifest.json) 指定论文、实验、两个对照组、XLSX 单元格、PDF 页、定位表达式、单位、条件与重复。程序检查原始文件哈希与 XLSX 行标签、提取数值及误差、生成比较和保守的可比性判断。PDF 对应段落和方法经助手视觉核查，不是独立人工 Gold。这里是配置驱动的定点提取，不是任意论文自动筛选或通用 PDF 表格解析。

## 真实研究与比较

- [Wu 等（2022），表 1 与物理页 2–3、7](https://doi.org/10.5194/soil-8-645-2022)：普通稻田土壤盆栽，2020 年、每组 3 盆。本次选用双方均 225 kg N/ha、无秸秆、¹⁵N 标记尿素的处理。AWD 累计 **4.48±0.12**，CF **4.02±0.30 kg N₂O/ha**，均值±SE；表中字母 b 对 c，作者按 Duncan 表注作组间区分。不同 N、秸秆与标记处理不是独立研究，本次没有将其额外计数。
- [Lagomarsino 等（2016），物理页 3–4、8](https://doi.org/10.1016/S1002-0160(15)60063-7)：意大利田间 2012 年 AWD **4.91**、永久淹水 **0.80 kg N₂O-N/ha**，全年季节累计；同年 120 kg N/ha、含硝化抑制剂肥料。每种水制度只有一个田块，2012 年 3 个箱位被作者称为伪重复，不能作为独立水处理重复；正文指定段落未提供累计值误差及该成对比较的显著性，保留未知。2013 年田块调换，未将两个年份当作独立研究。

两项均为 AWD 数值高于各自对照的**单研究观察**，不构成经证实的跨研究共同因果效应。盆栽与田间、干湿阈值、肥料和水制度不同；两项数值分别以 N₂O 和 N₂O-N 表示，可在有依据时做化学计量换算，但本次尚未建立共同效应定义或完整方差，程序不直接比较或合并。田间伪重复进一步限制因果解释。未把作者提出的硝化或反硝化机制当作本次直接验证结果。

## 验收与限制

同一 Wu 记录在本次 `population_requirement=rice` 下作为核心候选，在既有盐碱主题下仍为盐度未知的外部参照；未知的群体定义会拒绝。共享处理只在同实验且有明确组身份时提示，缺身份保留未知；不同论文和不同年次不自动被认定独立。综合的 `primary_conclusion` 与空 `findings` 均表示共同发现证据不足。Candidate 状态未升级。

本次程序直接组织了两篇原始研究的结果并输出不可定量比较及原因；**尚未完成可靠的跨论文共同观察**，也未完成同效应量换算及独立田块复核。相同方向和显著性不能代替这些条件。已有针对性综合及转换回归分别通过 11 项；受控测试不等于科研事实核验。未进行 Meta 分析或推广性结论。
