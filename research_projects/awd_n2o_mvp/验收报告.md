# v0.9 科研证据综合验收

运行入口（在仓库根目录，Python 需安装 `pdfplumber`）：

```sh
python research_projects/awd_n2o_mvp/run.py --manifest research_projects/awd_n2o_mvp/manifest.json --sources outputs/awd_mvp/sources --out outputs/awd_mvp/run
```

入口读取公开原始 XLSX 和 PDF，校验文件哈希，按人工指定的表格位置或 PDF 上下文提取，调用既有转换和综合接口，再输出 `analysis.md`、`normalized_evidence.json`、`synthesis.json` 和 `run_log.json`。已实际执行：两篇已核论文均解析，生成两条比较和一组跨论文判断。结果见[自动科研分析](analysis.md)、[规范化证据](normalized_evidence.json)、[综合](synthesis.json)、[运行记录](run_log.json)。

验收分别为：工程流程成功；已处理两条数据经助手核对原文但仍为 Candidate；Wu 记录了 3 个独立盆，Lagomarsino 水制度每组只有 1 个田块、箱位为伪重复；两项可附条件并列但定量比较条件尚未建立；目前没有可靠的跨论文共同发现。

人工决定纳入标准、选择来源、指定处理与对照、行列、页码、上下文模式及试验设计信息，并实际核对原文。程序读取原始数值及误差，验证标签、PDF 指标、年份、处理顺序和单位，再生成计算结果。PDF 匹配不唯一时该条保留失败，不阻碍其他论文：用包含两个候选的宽泛表达式实际验证，记录“匹配数为 2”，仅输出另一篇。

原单位分别为 kg N₂O/ha 和 kg N₂O-N/ha；程序对后者按名义分子量 44/28 换算，原值和误差仍保留，误差未报告时不补造。Lagomarsino 2012 年原始均值 4.91 对 0.80 计算为 +513.75%，与作者讨论中的 +307% 存在未解决冲突，保留两者；不能由程序百分比推断显著性。两项研究的试验尺度、氮肥和水制度不同，单位换算不解决设计可比性。

新增候选按公开全文、AWD 对照和独立灌溉小区条件选择 [Sibayan 等（2018）](https://doi.org/10.1080/00380768.2017.1401906)；2026-11-01 出版商全文请求返回 HTTP 403，无法获取或解析，未用摘要补造数值。**新增第三篇真实论文的解析验证未通过。** 清单支持多篇；不能将受控测试或既有两篇视为第三篇验证。

工程回归：既有综合测试与转换测试分别 11 项通过。自动化只覆盖清单指定版式，未完成通用 PDF 理解、独立人工 Gold、统计合并或可靠跨研究共同因果判断。
