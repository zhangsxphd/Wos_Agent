# 科研应用：范围、来源和限制

- [生物炭与盐碱稻田产量、土壤盐分](01_biochar/report.md)是第一项应用基准；[证据表](01_biochar/evidence.xlsx)和[缺失清单](01_biochar/evidence_gaps.md)属于其公开副本。
- [氮肥管理与盐碱稻田产量、NH₃ 和 N₂O](02_nitrogen/report.md)是第二项独立分析；另见[证据表](02_nitrogen/evidence.xlsx)和[缺失清单](02_nitrogen/evidence_gaps.md)。

两项都在已有100篇文献池内筛选，排除文献主要按题名及已有候选初筛，不能等同完整系统综述。结果来自不同历史提取流程，关键结论针对原文及必要补充材料回查；不具备统一的独立人工参考集，不报告模型准确率。气体观测时段、不同重复层级、统计字母、图文矛盾和可能共享的试验均应按照各报告及证据表理解。

公开证据表保留原有数据行、来源 DOI、位置、数值与 SHA-256；包含个人目录的本地文件路径被替换为“本地持有；以DOI和SHA256核验”。公开副本不可单独重建已授权的 PDF 或补充材料，用户需在有合法访问权的环境中以 DOI 和哈希核对原文。第一项未经路径替换的原始基准和历史人工决定保留在本机，未被覆盖。

第二项应用于核对 DOI `10.3390/plants12132446` 第4页 Table 3 后修订：27.8% 与26.1%对应单位产量NH₃比较，而不是排放因子；排放因子三组同标a。正文表述本身并列两种指标且含糊，不据此断言作者明确给出了冲突的因子数据。[修订报告](02_nitrogen/report.md)与[证据表](02_nitrogen/evidence.xlsx)是当前基准；[原报告](02_nitrogen/original_report.md)、[原证据表](02_nitrogen/original_evidence.xlsx)和[原缺失清单](02_nitrogen/original_evidence_gaps.md)仅供追溯。原表中的本机路径同样已去标识。

在应用基准冻结后，另以[土柱试验](../paper_reading_validation/01_nitrogen_soil_column.md)、[多年田间试验](../paper_reading_validation/02_organic_field_trial.md)和[Meta分析](../paper_reading_validation/03_global_meta_analysis.md)进行单篇日常科研阅读验收；这些单篇报告不是第三项专题分析，也不修改原基准。
