# 单篇分析三：有机投入对盐影响耕地作物与土壤的全球Meta分析

**论文：** *Response of crop productivity and salt-affected soil properties to organic additions: A global meta-analysis*；[DOI 10.1016/j.fcr.2026.110607](https://doi.org/10.1016/j.fcr.2026.110607)。这是一项二次证据综合，**不是一项水稻田间试验**；页码为论文PDF物理页码。

## 研究问题与假设

作者研究有机投入相对于未施有机投入的对照，如何影响盐影响耕地的作物产量、生物量和土壤性质，以及作物、投入类型、养分和环境条件是否与效应差异相关（第2页引言、2.1节）。作者希望辨别盐分缓解与养分供给的相对作用，也明确提出营养投入水平可能改变有机投入的效果；这些是研究动机和待检验关联，不预先认定机制已获证明。

## 研究设计与方法

作者检索WoS、Scopus、CNKI和ScienceDirect，截止2025年6月；报告最初约1000篇、题录筛查210篇、全文评估189篇，最终纳入159项研究、1632组处理—对照配对。纳入条件包括至少3个独立试验重复和盐土ECe>2 dS/m；独立重复属于各原研究的田块或盆，不是本Meta分析新增试验的重复。1632对比较可能来自同一研究、共享对照，不能当作1632项独立研究（第2–3页2.1节）。

效应量为处理均值与对照均值之比的对数LnRR；论文描述按研究设置随机效应、以999次bootstrap计算区间，并使用亚组、Meta回归及随机森林。不同土水比EC通过经验系数换算为ECe，并对直接测得ECe的140条观测进行了敏感性分析（第4页2.3–2.5节）。换算引入模型依赖；研究间共用对照、异质性和跨研究混杂使估计不等于统一条件下的随机试验。最终筛选流图、部分敏感性图在补充材料；其DOCX正文表格可从压缩包读取，但标准文档解析存在损坏关系，图像未在本次逐一核验。正文汇报了方法和部分结果；本分析没有逐项重建原始研究及代码。

## 作者结论与逻辑链

作者认为有机投入总体与产量、生物量及CEC增加、盐分指标降低相关，并报告响应随作物、材料和管理条件而异（第5–6页3.2–3.4节）。论文逻辑链为：**纳入带对照的原研究 → 汇总相对效应 → 按背景分组及模型探索差异 → 对可能的盐分、养分和生物量路径提出解释与管理建议**。这是证据综合和调节因素分析：跨研究差异可能同时涉及灌溉、土壤、作物和施肥，不能单凭Meta回归或随机森林的重要度证明某因素独立造成效应或建立可普遍套用的最佳施肥阈值（第4–6页）。

## 创新性、比较与不足

**作者自述：** 第2页称其综合不同作物与有机投入类型，并结合随机森林分析潜在非线性驱动；论文亦承认此前已有盐土有机投入的Meta分析，故“有机投入可影响盐土作物”并非本文独创。

**已有文献支持的可核验增量：** 相比同库Yu等2025年的干旱区生物炭综合 [10.3390/agronomy15112609](https://doi.org/10.3390/agronomy15112609)（其第1–2页），本研究覆盖更广的有机材料、作物和产量—土壤指标，并包含直接ECe子集敏感性分析。前者聚焦干旱条件与生物炭，报告EC平均上升34.63%；本研究总体报告EC下降27.2%。材料、气候、纳入标准、结局组成和研究集合可能不同，**这两个汇总方向不能当作同条件下的直接冲突，也不证明任一论文错误**。两文原研究可能重叠，尚未逐篇排重，不可将它们视为完全独立的验证。

**主要不足：** 样本覆盖与质量依赖原研究，重复比较和共享对照的处理是否充分需结合数据和代码复核；经验换算ECe有不确定性，直接测量子集结果较总体小。纳入作物不只水稻、生态与管理高度异质；有机肥本身带入养分，较无有机投入对照的效应混合材料与养分投入差异。作者讨论也指出表层降盐不能证明农田整体盐分净移除，长期与深层过程资料不足（第10–12页讨论）。不能把N<50 kg/ha等分组边界直接当成经因果验证的最佳施肥阈值。
