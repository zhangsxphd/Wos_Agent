# v0.3 摘要补全

当前执行入口已更新为 [OpenAlex 批量 DOI 修复](openalex_batch.md)：v0.5.6 恢复 Semantic Scholar DOI 批量查询，OpenAlex 默认批量查询，并支持 `--refresh-provider semantic_scholar|openalex`。本页保留初版三来源设计和摘要校验规则，历史真实报告不改写。

## 数据边界

WoS 为主书目来源；补全只添加/维护摘要字段和 `abstract_enrichment`，不改动 uid、title、authors、publish_year、source_title、doi、issn、eissn、times_cited_wos、matched_queries、provenance_history。输入 JSONL 和原始 WoS 响应不覆盖。enrichment 的同名 manifest 保留原检索清单，摘要获取时间与原检索时间分开。

三个客户端统一返回 provider、provider_id、doi、title、year、abstract、url、retrieved_at、raw。外部 DOI 不从请求 DOI 推定；缺失 DOI 的外部结果无法通过精确匹配。缓存是外部响应证据，JSONL 是机器可读的标准记录，CSV/XLSX 仅为导出快照。

## 校验和选择（policy version 1）

1. 规范化 DOI 必须精确一致。查找仅使用 DOI，没有题名搜索。
2. WoS 与 provider 题名经 NFKC、casefold、去标点后，标准库 SequenceMatcher 相似度至少 0.85；缺少题名拒绝。
3. 年份差的绝对值最多 1；记录差值和警告。缺失年份记 year_match=null 并警告，依靠精确 DOI 和题名核验；差值超过 1 拒绝。
4. 摘要至少 120 字符、最多 60,000 字符；拒绝空文本、未清理标签、NUL、大量控制字符或极低字母比例。此规则只决定摘要是否可用，不删除论文。全部候选及拒绝理由仍保留。
5. Crossref 仅提取 JATS/XML/HTML 可见文本、展开实体、折叠空白，保留上下标相邻关系。S2 原文保存；OpenAlex 按整数位置确定性重建，缺失位置/重复位置不猜词，返回空摘要和警告，原始 index 仍保留。
6. 多个有效摘要经相同文本规范化后两两相似度至少 0.90，标记 corroborated=true，按 Crossref > Semantic Scholar > OpenAlex 选源。摘要本身仍保存来源原文，不按比较文本重写。
7. 任意一对低于阈值，保守标记 status=conflict；原来没有摘要时 canonical abstract=null。如输入已有摘要，则显式保留旧摘要及来源/时间，previous_abstract_retained=true，选择理由记录这一行为。相似度只是确定性审核规则，不证明学术内容相同或不同。

状态：found、missing、missing_with_errors、no_doi、conflict、retained_previous。provider_results 中 found 表示找到了元数据，不等于找到了有效摘要；abstract_accepted 标识摘要校验是否通过。

## 缓存和故障

缓存路径为 `data/cache/{crossref,semantic_scholar,openalex}/<normalized DOI SHA256>.json`。保存原始 JSON、provider、lookup_doi、首次 retrieved_at、HTTP 状态及稳定状态 `success`/`no_abstract`/`not_found`（兼容历史 `ok`）。默认命中缓存不发请求。404（包括非 JSON 404）和 HTTP 200 的空记录负缓存；有元数据但无摘要仍是成功缓存。401/403/429/5xx、连接失败不负缓存；可以稍后重试。解析失败的成功响应保留原始缓存证据，`--refresh` 可替换。

`--refresh` 对本次 DOI 刷新缓存；`--cache-only` 禁止网络，未缓存的来源记录 cache_miss；两者互斥。来源失败不妨碍其他来源和论文。Coverage 的 requests 包含重试，cache_hits 包括成功/负缓存，not_found 包括负缓存重放，errors 为失败 lookup 数。found_by_* 只统计通过全部摘要校验的候选；found_by_multiple_sources 包括最终存在冲突的多个有效候选。abstract_found_total 统计最终非空摘要，conflict_count 单独列出。重新处理已有摘要时，保留旧摘要也计入最终覆盖率。

三个 Key 的环境变量/本地 .env 值及其 URL/JSON 转义形式均在写入 cache、canonical、report、manifest 和导出前检查。错误只输出固定代码和 HTTP 状态，不输出响应错误正文或请求 URL。外部来源仅接收自己的 Key（S2 x-api-key、OpenAlex Authorization Bearer），WoS Key 从不用于外部请求；Node 导出子进程移除这三个环境变量。生成的测试 sentinel 为临时模拟值，不使用真实凭据。

服务端 Retry-After 超过 60 秒时，不长时间阻塞程序；同一客户端保留冷却截止时间，后续未缓存的 DOI 在此期间记录 provider_cooldown，不向该来源发请求。已有缓存仍可使用。

## 使用

```bash
cd ~/wos-research-agent
source .venv/bin/activate
python scripts/enrich_abstracts.py data/processed/saline_paddy_v03_smoke_input_10_20261003.jsonl \
  --output data/processed/my_enriched.jsonl
python scripts/enrich_abstracts.py data/processed/saline_paddy_v03_smoke_input_10_20261003.jsonl \
  --output data/processed/my_cache_replay.jsonl --cache-only
python scripts/export_records.py data/processed/my_enriched.jsonl \
  --output-prefix data/exports/my_enriched --include-abstracts
python tests/run_offline.py -v
```

离线测试入口禁用 Python socket 连接；所有 HTTP 使用 Mock。XLSX 在本地 Artifact Tool 运行时生成并独立 XML 读回校验。默认 Records 不含完整摘要；可选 Abstracts 六列为 uid、doi、title、abstract、abstract_source、abstract_status。CSV 保留原有完整摘要列；JSONL 始终保留完整摘要。摘要超过 Excel 单元格 32,767 字符时，完整摘要 XLSX 导出明确报错，可改用 JSONL/CSV。

## 官方接口依据（2026-10-03 核查）

- [Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/tips-for-using-the-crossref-rest-api/)：`/works/{doi}`，公开 API、User-Agent、缓存和退避。
- [Semantic Scholar API](https://api.semanticscholar.org/api-docs/snippets)：Graph paper API 接受 DOI 标识和字段选择；Key 可选。
- [OpenAlex DOI 单记录](https://help.openalex.org/api/get-single-entities/)：外部 DOI URL 直接查找。
- [OpenAlex 鉴权](https://help.openalex.org/api/authentication/)：基础无 Key 查询可用；Key 可通过 Bearer header 传递。
- [OpenAlex Work 字段](https://help.openalex.org/data/works/attributes/)：abstract_inverted_index 是词到位置列表的映射。

真实验证限制为已有 v0.2 候选池中的前 10 条 DOI 记录，所有匹配 query 和历史保持。该样本用于验证程序，不能代表完整研究文献的摘要覆盖率；不进行论文评分、自动排除或 PDF 下载。
