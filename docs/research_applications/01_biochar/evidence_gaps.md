# 关键证据缺失与待核对项

1. **试验是否共享地块。** `10.1007/s42773-024-00332-3` 与 `10.3390/su16031001` 的地点、品种、处理及基线高度相似，但施炭年份叙述不同；需作者、试验登记或原始小区记录确认。与 `10.3390/agronomy14092159`、`10.1007/s42773-026-00619-7` 是否共享地块也未知。当前不合并、不按彼此独立计算总体效应。
2. **土壤EC单位与测法。** `10.3390/agronomy14092159` 和 `10.3390/su16031001` 的基线ECe表头写 `µs m−1`，相似长期试验写 `dS m−1`；需核对原始记录。不同研究的ECe、1:5和其他浸提方法不可直接换算。
3. **图中精确值。** `10.1002/ldr.5442` 的处理级水稻产量和EC只见图柱或总体范围，需原始数据或作者表格；目前只使用显著性及方向，不伪造精确值。
4. **图文冲突。** `10.3390/agriculture16131434` 的产量正文称SB1P1、SB3P2均显著低于CK，而Figure 1f对应字母与CK分别有重叠；需原始统计或作者澄清。其EC比较为炭与秸秆等复配对CK，单独炭效应不能从该比较分离。
5. **试验单位和阈值。** `10.3390/agronomy13030815` 同时写4盆及3次重复，表注显著性阈值写0.05%，方法写5%；需澄清盆、公共水池和检验阈值。高炭剂量仅为盆栽条件。
6. **取样季节与配方。** `10.3390/plants14233616` 的收获后EC表未明确对应稻季还是麦季；炭改性有机肥与普通有机肥组成不同，不能将差异完全归因于炭。
7. **范围限制。** 89篇排除主要依据题名与既有候选，未逐篇全文复审；本轮只有用于分析的论文关键处理及结果回看原PDF，仍可能漏掉题名不明显的相关研究。当前尚无足够一致且可独立计数的田间样本计算汇总效应。
