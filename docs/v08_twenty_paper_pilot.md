# v0.8 全文 Pilot：首批核查与补充材料

更新日期：2026-10-29。

本阶段使用现有全文技术准入流程，先保留此前三篇结果，再对五篇不同研究设计的文章进行候选提取和重点核查。五篇尚未完成全部字段的独立审核；已准备下一批五篇，尚未完成其提取。论文准入检查证明文件身份和解析重现，不证明科学结论正确，也不保证表格或所有字符均无解析错误。

本轮通过当前 Codex 会话处理材料，未调用付费 API；此前用户提供的网页版结果保留原有来源标记，不冒充标准化 API 运行。用户提供的五篇核查意见作为独立来源保存，其作者身份和独立性未另行验证；不能自动转换成历史人工 Gold 或计算准确率。

## 核查方式

- 按具体字段判断影响：排版和不影响目标结果的缺失可以记录后继续；符号、单位、处理与对照、独立重复、显著性以及可能影响结论的冲突需保留证据和限制。
- 对论文的正文、表格、图和补充文件分别记录来源与位置；作者报告、来源冲突和方法风险不得合并成未经证实的单一结论。
- 补充文件从出版商或授权渠道获取，记录 DOI、来源、文件哈希与可用性；无法取得时标记相关字段的限制，必要时请用户协助下载。
- 不根据期刊影响因子判定单篇论文的可靠性；按实际研究设计、原始证据和结果一致性评估。

## 补充文件进展

已从相应出版商文章页面取得七份补充文件：生物炭长期试验一份、转录组论文四份、氮磷径流研究一份及全球荟萃分析一份。文件及其哈希清单保存在本机忽略目录，不作为本仓库公开内容。

生物炭补充文件提供了地块内取样方法；这些子样不应自动视作独立田间重复。转录组补充表的四个差异表达工作表分别有 3982、3463、977、596 行数据，与正文报告的数量一致；这些行均满足表中给出的 `abs(log2FoldChange) >= 2` 和 `padj < 0.05`，但该检查没有重分析 FASTQ，也不能消除正文中其他数据疑点。径流补充文件包含水量表、统计表和计算说明；拿到文件本身不能证明统计设计合理。荟萃分析补充 Word 文件包含两张表和九幅图，内部存在无法解析的文件引用；已从文件包读取目录，详细内容仍须核实。作者在文章页面说明原始数据可按要求提供。
