# v0.5 Full-text Resolver + Screening Profile

本轮保留 canonical WoS/enrichment JSONL 和旧版 Evidence 文件。新增 supplementary Work lookup、全文文件、解析文件、章节提取和筛选 sidecar，不调用 WoS、Crossref、Semantic Scholar 或模型 API。

## v0.4 兼容修复

同一篇内，findings 只按 `(source, evidence_text)` 精确去重，保留首次出现的条目。没有模糊或语义去重；原有 inference finding 索引随去重重映射。旧 Evidence JSONL 不重写，新 sidecar 的 abstract_evidence 使用规范化后的副本。原始 33 条摘要 findings 规范化后为 32 条。

Schema 可选新增 `evidence.author_interpretations`：`text`、`claim_type`、`source`、`anchor`。旧 `mechanisms_explicit` 保留；未人工分类的旧陈述兼容迁移为 `other`，不自动标记 causal。新全文作者解释分别标记 pathway/hypothesis 等，保留作者的 tentative language。作者解释不是模型推理，也不表示独立验证了因果机制。

## 来源与下载

`scripts/fulltext/openalex_content.py` 为独立 supplementary lookup。查询 DOI 或 OpenAlex Work ID，返回 id/doi/title/year/type 以及 open_access、best_oa_location、locations、has_content、content_urls。原有 enrichment batch provider、缓存和 canonical 内容保持不变，新 Work cache 位于 `data/cache/openalex_work/`。

下载优先顺序：OpenAlex TEI XML → OpenAlex cached PDF → best OA PDF → 其他标为 OA 的直接 PDF → OA landing page 明确公布的 PDF → unavailable/error。landing page 最多两个，仅读取 `citation_pdf_url` 或 PDF 类型 link，不猜 publisher URL、不递归抓取、不执行 JavaScript、不登录、不解验证码、不绕过访问限制。

官方依据：[OpenAlex Fulltext](https://help.openalex.org/access/fulltext/) 说明 `has_content`/`content_urls` 和 `.grobid-xml`/`.pdf` 下载入口；[Authentication](https://help.openalex.org/api/authentication/) 说明 Bearer header；[Locations](https://help.openalex.org/data/locations/) 说明 OA location、版本和 PDF/landing links。

Key 仅从项目 `.env` 读取，仅发给 `api.openalex.org` 或 `content.openalex.org`，不放入 URL。重定向到 publisher/CDN 后不给第三方 Authorization。只使用公开 HTTPS URL。404 Work lookup 可负缓存；429/timeout/5xx 不生成 Work negative cache，失败下载下一轮可重试。默认相邻请求间隔至少 1 秒、最多重试 1 次、超时 25 秒，单次正文最大 30 MB，重定向最多 5 次。超过 60 秒的 Retry-After 作为 retry_later，不长时间阻塞。

OA status、license、version、host_type、landing_page_url、pdf_url 和 content URL 写入 sidecar。OpenAlex 缓存文件的具体来源版本/许可不能仅凭 best_oa_location 推断，因此下载 manifest 的 version/license 可以为 null；可用 OA location 信息仍独立保留。

## 命令

```bash
cd ~/wos-research-agent
source .venv/bin/activate
pip install -r requirements.txt

python scripts/resolve_fulltexts.py \
  data/processed/saline_paddy_v03_openalex_batch_enriched_20261003.jsonl \

  --output data/fulltext/runs/my_v05_fulltext.jsonl
```

先尝试 3 条无摘要，再尝试另外 5 条 completeness.needs_fulltext，最后尝试剩余两条。`--metadata-only` 只查 Work；`--cache-only` 完全不联网；`--refresh` 明确重新查 Work/获取内容，与 cache-only 互斥。必须使用新的输出路径。

如果 DOI lookup 返回 404，可使用旧 OpenAlex cache 已保存的精确 DOI–Work ID 对应关系补查 ID。返回 Work 的 DOI 必须与原记录规范化 DOI 一致；不做标题匹配。

```text
profiles/saline_paddy.yaml

data/fulltext/raw/<sha256>.tei.xml|pdf

data/fulltext/runs/<run_id>.jsonl + manifest
data/raw/fulltext_extraction/<run_id>/<document_sha256>/
```

原始内容按 SHA256 保存，不覆盖已有文件；每次 resolver manifest 留档。error、unavailable、available 分开；available 并不自动等于 parse 成功。challenge HTML、非 TEI XML、非 PDF、加密 PDF 或不安全 XML 不视为可用全文。下载和解析状态分别报告。

TEI 解析 title、abstract、body section/heading/paragraph、figure/table captions、references。稳定 paragraph_id 与 section_id 绑定零基 `[char_start,char_end)` 字符位置，位置基于原始 parsed paragraph 文本，非 XML 字节位置。captions/references 分离，不能直接作为本研究正文 finding。Grobid 扁平 div 的 Methods/Results/Discussion 范围沿明确标题继续；分区路由仍需人工复核。PDF 保存页码、稳定 page paragraph anchors 和元数据，不能自动声称已恢复准确章节；页码范围可供人工路由。

## 章节提取与来源冲突

```bash
python scripts/build_fulltext_evidence.py \
  data/processed/saline_paddy_v03_openalex_batch_enriched_20261003.jsonl \
  --abstract-evidence data/evidence/20261003_192326_169425_evidence_57015bbc_evidence.jsonl \
  --fulltext data/fulltext/runs/my_v05_fulltext.jsonl \
  --prepare-only --output data/evidence/my_v05_prepared.jsonl
```

`extraction_provenance.requests` 指向 Methods/Results/Discussion/Conclusion 的独立请求文件。单块最多 12,000 字符，长段落按原文字符区间拆分，绝不把整篇一次提交给模型。PDF 暂按页分块并标记 requires_review。每次请求的 section payload 内容决定 `chunk_key`；人工响应保存到：

```text
data/manual/my_review/responses/<document_sha256>/<chunk_key>.json
```

每个人工响应包括该块能支持的设计、处理、采样、测量、分析/统计方法、结果、作者解释和限制，无法支持的字段为空。可填写空响应表示已审核该块但没有新增事实。响应只能引用该块实际提供的段落和字符区间；所有正文数值/claim 必须是原文片段。

```bash
python scripts/build_fulltext_evidence.py \
  data/processed/saline_paddy_v03_openalex_batch_enriched_20261003.jsonl \
  --abstract-evidence data/evidence/20261003_192326_169425_evidence_57015bbc_evidence.jsonl \
  --fulltext data/fulltext/runs/my_v05_fulltext.jsonl \
  --manual-dir data/manual/my_review/responses \
  --output data/evidence/my_v05_reviewed.jsonl
```

摘要与全文分别保留在 `abstract_evidence`、`fulltext_evidence`，全文明确标记 evidence_source=fulltext；不覆盖 abstract evidence。冲突必须同时指向摘要 supported fact/finding 和全文 paragraph anchor。

人工完成对比后可填写同一目录的 `comparison.json`，包含 `reviewed: true`、`document_sha256`、`abstract_record_sha256`、`conflicts: []`。摘要哈希为旧版原始 Evidence 单条记录的 `json.dumps(..., sort_keys=True, ensure_ascii=False)` UTF-8 SHA256；全文为 raw manifest SHA256。每个冲突包括 description、abstract_anchor 和 fulltext_anchor。未提供审核记录时 conflict_check_status=not_assessed；即使 evidence_conflict=false，也不能将其理解为已经排除冲突。

单块错误留存安全 raw response，跳过该块并在 extraction_provenance.errors 记录；不会抹掉摘要层或其他有效块。包含已知 API Key 的响应不写入 raw/output。完整度根据通过验证的内容计算，不能仅因为获得文件而升级。

## Screening Profile 与完整度

Profile 把 eligibility_status 与 evidence_role 分开。core_experimental 要求结构化证据支持盐碱背景、rice/paddy 系统、实验或 field observational scale，以及直接相关主题。综述保留 review_synthesis，区域模型保留 regional_context；不直接 exclude。信息不足使用 uncertain/needs_fulltext，本 profile 不自动排除论文。

```bash
python scripts/screening_profile.py \
  data/processed/saline_paddy_v03_openalex_batch_enriched_20261003.jsonl \
  --evidence data/evidence/my_v05_reviewed.jsonl \
  --profile profiles/saline_paddy.yaml --output data/evidence/my_rescreened.jsonl
python tests/run_offline.py
```

保留 v0.4 completeness_before；v0.5 after 计算 has_methods、has_treatments、has_measurements、has_results、has_mechanism、has_limitations。有有效全文提取且 methods+treatments+measurements+results 充分时 needs_fulltext=false；机制与限制的有无独立显示，不要求臆造缺失内容。未获得/提取全文时保留此前 needs_fulltext 状态。这不是论文质量或创新性评分。

has_mechanism 只计入已分类的 causal/pathway/hypothesis 作者机制表述；association 和尚未分类的 other 不自动算机制。hypothesis 仍只是作者假说，不是因果验证。

## 首轮真实结果（2026-10-03）

仍为原来的 10 篇：10 Work matched，7 OA、3 closed；1 篇具有 OpenAlex TEI/PDF 内容，取得并解析了该篇 TEI 和 21 页缓存 PDF。其余 9 篇未恢复全文：3 closed，6 为访问限制或未公布直接 PDF。没有绕过 403/验证码/登录限制。

目标 8 篇（3 无摘要 + 5 completeness needs_fulltext）均尝试过，恢复 0 篇；成功的全文来自原有高完整度的一篇。因此 needs_fulltext 为 8→8，不能声称覆盖率改善。该篇新增 Methods/采样/分析/统计细节、DO/ORP/EC/SOC 等测量内容、9 条全文 findings、3 条作者解释、2 条明确限制。9 条全文 findings 包含与摘要一致的结果，不能称作 9 个新科学发现。

182/182 离线测试通过（135 原有 + 47 新增）。真实验证总共 41 次 HTTP 请求，分阶段和 response rate-limit headers 均有留档；最终 cache-only replay 为 0 HTTP。完整逐篇状态及前后完整度见 `data/reports/v05_fulltext_validation_20261003.md` / `.json` / `.csv`。
