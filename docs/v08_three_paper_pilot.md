# v0.8 三篇全文提取开发试跑

本阶段采用已有的三篇技术准入 PDF，并将用户粘贴的网页版模型回答作为候选结果。首篇有已审核参考记录，可用于字段级来源对照；后两篇尚无人工参考答案。候选提取和定向核对不构成系统准确率或独立 Holdout 结果。网页模型身份、实际 token 数、上传文件及会话隔离状态不能从粘贴文本独立验证。

- 首篇此前 14 条人工记录的主题在候选回答中均有涉及；已发现限值符号转录错误。论文的冲突说法保留多个来源，不合并成单一真值。
- 后两篇完成对试验设计及部分图表、数值和原文冲突的定向核查；并非全文逐项验收，补充材料尚未核验。
- 研究用原始 PDF、解析数据、模型回答、审核记录以及生成的本地结果页面保存在 Git 忽略的 `data/`，不包含在公共仓库中。
- 下一阶段可按小批次试运行，优先核对处理、对照、重复、数值单位、统计显著性和原文证据；在参考答案和科学裁决不足时不宣称准确率。

## 实验性 API 候选

`scripts/pilot_v08/` 是此前准备的独立 API 候选原型，并非本次网页提取的执行器，也没有真实 API 端到端验证。它需要本地的受保护数据和可选 PDF 解析依赖；公开仓库不含这些数据。运行真实 API 需要有效 API 凭据、明确授权和可能产生费用，`run` 入口要求显式 `--approved`。当前用户选择使用 Codex 和网页版 ChatGPT 额度，**本阶段没有通过该原型发起付费 API 请求**。

该原型的格式检查和精确字符串匹配不证明科研含义正确；页面图像证据、处理与比较对象、数值单位和显著性仍需要原文核对。PDF 页面渲染会发送到模型提供方，启用外部服务前应确认数据使用权限与账户设置。
