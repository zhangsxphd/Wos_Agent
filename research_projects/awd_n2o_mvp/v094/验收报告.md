## 修正结果

- [Liu 2026](https://doi.org/10.3389/fpls.2026.1756990) 原方法 2.2 为田间、混凝土渗漏计，每处理 3 个独立渗漏计。修复前单凭 `lysimeter` 判为盆栽；修复后分别记录田间场景、混凝土渗漏计设施、渗漏计单位与每处理 3 个。两个年度为同一装置的重复观测。2019 图值仍为助手目视近似 AWD 约 2.3、CF 约 1.9 kg N₂O/ha，读图误差约 ±0.1，并非 SD 或原文精确数字。程序另从正文 PDF 第 6 页提取作者报告的 **2019–2020 季节累计相对增加 20.59%–28.72%**；不反推出各组精确值。
- [Sander 2020](https://doi.org/10.3390/agriculture10080350) 表 3 的原始 252、120 kg CO₂eq/ha 为 N₂O 专属 GWP；PDF 第 8 页给出 265，程序推算约 0.951、0.453 kg N₂O/ha。报告保留过去“系数未确认”的历史及已找到方法依据后的新状态，不再显示仍无法换算；原表 52.38% 与按 CF 为分母的 110% 口径差异仍未裁定。地形与处理混杂。
- 原文直接报告质量、N₂O 专属 GWP 反算与人工读图近似分别记为 `reported_n2o_mass`、`inferred_from_n2o_specific_gwp`、`manual_figure_approximation`；不自动赋予相同核查等级、误差或统计可靠性。单位统一后仅消除量纲问题，不消除设计差异。原文位置、模型/程序提取与独立人工 Gold 仍分开。
- PDF 库为可选依赖，见 `requirements-pdf-layout.lock.txt`。指标分类和换算测试导入时不再加载 `pdfplumber`；需要解析 PDF 时才导入，portable 原有覆盖未删除。无 pdfplumber 的系统 Python 已单独运行该测试文件；完整 portable 运行结果另列于运行日志之外。

## 候选与确认

从已有全文直接生成紧凑候选；程序给出少量分字段片段、页码、可能的处理名称及 XLSX 同行关系，无法唯一匹配的组不自动配对：

```sh
python research_projects/awd_n2o_mvp/run.py --discover outputs/v092/fresh/wu.pdf outputs/v092/fresh/wu_table1.xlsx --out outputs/v094/intake
```

[精简候选确认 JSON](manifest_draft.json) 是实际生成结果，需先填研究问题、勾选 `include` 并将各人工决定写到 `edits`，每项包含 `field`、`value`、`reason`、`actor`。原候选带摘要校验，不能直接改写；改动前后和原因自动进入运行记录。多组和未知项不被自动选成对照。

已基于该自动草稿确认 Wu 表 1，并用同一入口直接运行：

```sh
python research_projects/awd_n2o_mvp/run.py --confirmation research_projects/awd_n2o_mvp/v094/confirmed_wu.json --sources . --out outputs/v094/confirmed_wu
```

这次助手确认链接了 PDF/XLSX、处理、位置及设计等；程序从原表读取 4.48±0.12 对 4.02±0.30，输出一条 Candidate；[修改前后记录](confirmed_wu_run_log.json)包含 27 项确认，其中部分为来源或可选元数据。候选不再堆入整篇正文，但关联同一论文的 PDF/XLSX、核实实验单位、明确表格列及手工编写定位模式仍需操作，不能声称已全自动。
