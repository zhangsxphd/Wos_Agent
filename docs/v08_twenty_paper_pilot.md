# v0.8 全文 Pilot：首批核查与补充材料

更新日期：2026-10-29。

本阶段使用现有全文技术准入流程，保留此前三篇结果，再分批处理五篇不同研究设计的文章。第二批五篇已形成 43 条初步候选；这些候选尚未经过完整的逐字段科研审核，不能视为 20 篇已完成。论文准入检查证明文件身份和解析重现，不证明科学结论正确，也不保证表格或所有字符均无解析错误。

本轮通过当前 Codex 会话处理材料，未调用付费 API；此前用户提供的网页版结果保留原有来源标记，不冒充标准化 API 运行。用户提供的五篇核查意见作为独立来源保存，其作者身份和独立性未另行验证；不能自动转换成历史人工 Gold 或计算准确率。

## 核查方式

- 按具体字段判断影响：排版和不影响目标结果的缺失可以记录后继续；符号、单位、处理与对照、独立重复、显著性以及可能影响结论的冲突需保留证据和限制。
- 对论文的正文、表格、图和补充文件分别记录来源与位置；作者报告、来源冲突和方法风险不得合并成未经证实的单一结论。
- 补充文件从出版商或授权渠道获取，记录 DOI、来源、文件哈希与可用性；无法取得时标记相关字段的限制，必要时请用户协助下载。
- 不根据期刊影响因子判定单篇论文的可靠性；按实际研究设计、原始证据和结果一致性评估。

## 补充文件进展

已从相应出版商文章页面取得七份补充文件：生物炭长期试验一份、转录组论文四份、氮磷径流研究一份及全球荟萃分析一份。文件及其哈希清单保存在本机忽略目录，不作为本仓库公开内容。

生物炭补充文件提供了地块内取样方法；这些子样不应自动视作独立田间重复。转录组补充表的四个差异表达工作表分别有 3982、3463、977、596 行数据，与正文报告的数量一致；这些行均满足表中给出的 `abs(log2FoldChange) >= 2` 和 `padj < 0.05`，但该检查没有重分析 FASTQ，也不能消除正文中其他数据疑点。径流补充文件包含水量表、统计表和计算说明；拿到文件本身不能证明统计设计合理。荟萃分析补充 Word 文件包含两张表和九幅图，内部存在无法解析的文件引用；已从文件包读取目录，详细内容仍须核实。作者在文章页面说明原始数据可按要求提供。

## 第二批候选与补充资料

用户提供了第二批三篇论文的六份补充文件：盐化稻田碳研究的地块及取样图、甘蔗试验的基因型和稳定性表，以及生物肥料试验的样本编号表和三个功能预测表。两份 PDF 与用户下载的原始压缩包内容逐字节一致；文件标题、表名或样本编号与论文正文相符，但这些字节未独立与出版商下载副本比对。原件、来源和哈希清单保存在本机。

当前主要核查发现：甘蔗研究的摘要和结果段中存在基因型编号与名称不一致，需分别保存材料列表、表格和摘要，不替作者选择正确名称；生物肥料研究的产量表中 G1 和 G2 同属显著性组 a，其正文报告的 2.75% 与按表中数值计算的 G2 相对 G1 的约 2.44% 不同。稻田碳研究的补充图实际内容与正文末尾的图名说明不一致，方法部分引用则与现有附件相符。

43 条候选的短文本锚点已在指定解析页中匹配，但锚点匹配不证明处理、表格行列、显著性或科学解释完全正确；尚未对所有图表或每项结果做独立核实。本批采用 Codex 会话辅助提取，精确模型标识未独立记录，历史提示词仅作为参考，不应误报为统一 API 请求。

## 状态与边界

- 五篇审查意见、结构化候选、原始全文、下载文件及交互页均留在本机 `data/`，避免公开未经核实的研究资料及可能受版权限制的全文。
- 第二批五篇已通过文件身份、哈希和解析重现检查，并保存初步候选；全面提取与科研核查仍未完成。
- 后续七篇已生成 60 条正文候选，随后根据用户提供的两份附件增加了两条补充材料观察。总计 20 篇均有不同程度的候选；这些候选不是逐篇完整科研审核，也不表示所有目标字段或数据已经提取齐全。
- 埃及灌溉试验正文的处理数算式与其图示不一致：正文写 3×2×3×3=72，图示列出四个堆肥—硫水平；新收到的补充表给出相应因素自由度 3、总自由度 71。相关信息分开保留，不自动改写论文。藜麦盆栽研究的补充文件记录了土壤和生物炭性质，盆内两株不应算成独立田块重复。
- 用户授权通过网页 ChatGPT 交叉核验，曾对公开产量数字进行一次数值和显著性解释核对。网页未读取论文原件，不能作为独立原文核查或标准化 API 运行。
- 未修改原始全文、历史 Gold、旧版审核决定或冻结组件；未进行模型准确率计算。

## 三篇表格的定向核查

对三篇论文的原始 PDF 表格开展局部视觉核查，新增 10 条独立版本候选及页码、文件哈希和行列位置，不覆盖历史结果。水稻施氮试验表中 N200 和 N240 的籽粒产量共享显著性字母；N200 相对 N160 的表格均值增幅与正文报道约 61.3% 一致。真菌试验的表 1、表 2 中部分显著性字母与摘要的概括表述需要结合比较基准解释，不能将不同字母结论套用到所有两组比较。

藜麦试验摘要中的两项百分比与以表格显示值及无炭组为分母计算的结果不同。普通炭数值在表中显示为整数，未舍入值未知，其差异可能受舍入影响；硅炭的结果在通常显示精度假设下仍存在较大差异，摘要与表格是否采用了不同统计基础仍待核实。相关作者报告和计算结果分别保存，不推断作者的公式。通过网页 ChatGPT 独立核对了公开数值算术，未上传原文，也未调用 API；网页回答并未阅读论文。三篇的局部检查不能视为 20 篇的完整核查或准确率评价。
