# 盐碱稻田氮肥管理：关键证据缺失清单

1. **共同结局不足。** 能在同一试验内比较产量、NH₃和N₂O的直接证据主要是 `10.3390/plants12132446` 的单地点土柱；尚缺多个独立盐碱田点、多季且覆盖三个结局的对照试验。多数纳入论文未报告其中一个或两个气态指标，不能补造。
2. **正文与表格冲突。** `10.3390/plants12132446` 的NH₃排放因子文字称200 kg N/ha较160低27.8%且显著，而Table 3为24.98%与26.01%、同标a；相对差按表值为−3.96%。表中NH₃总量相关正文百分比也不完全对应。需要作者或原始数据澄清；N₂O采样覆盖及排放量计算口径也应进一步核对。
3. **肥料与施用时间混杂。** `10.3390/plants15182814` 的每盆磷投入、肥料按面积剂量和盆内质量的对应关系需澄清；加堆肥也引入额外有机氮。`10.3389/fpls.2026.1882006` 正文的分次描述与补充Table S1各处理的时间分配不同，需原始施肥记录澄清。
4. **独立重复。** `10.3390/plants14040543` 未清楚报告独立小区数，主副区描述不一致，误差类型不明。其显著性仅保留为作者表内报告。多年重复不等于每年不同小区；土柱重复不能当独立田点。
5. **疑似共享试验数据。** `10.1007/s42773-026-00619-7` 与 `10.3389/fpls.2026.1756775` 同地区年份重叠，且2024年225 kg N/ha无秸秆均为4.89±0.16 t/ha；需要地块编号、试验登记或作者说明，不能仅凭这些线索断定同一数据，也不独立加权。
6. **图像与原始值。** `10.3389/fpls.2026.1882006` 部分气体及产量图无精确组均值；`10.3390/plants12132446` 的N₂O图也未给出可准确读取的全部绝对值。应获取作者原始表或数据；本报告只引用作者报告的百分比与图中标注，不把图高估读冒充原始测量。
7. **覆盖限制。** 100篇外文献未检索；排除论文主要依据题名和既有候选而非全面重审全文，因此相关研究可能漏入。未建立独立人工参考集，无法计算字段准确率。
